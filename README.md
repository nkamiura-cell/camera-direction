# 撮影設計 AI / KOBAN Prototype

既存の撮影香盤表の構造を大きく変えず、「制作物→カット設計→撮影枠→仮香盤→人間による編集」を想定したUIプロトタイプです。

## 今回入れているもの
- 既存香盤に近い表形式UI
- カットイメージを撮影枠に紐付け
- AI初稿を想定したサンプルデータ
- 撮影可能時間の設定
- 3時間制約を前提にしたAIアシスト表示
- 行の追加・複製・削除
- 右側インスペクタからの編集
- ブラウザ印刷によるPDF化
- CSV出力（スプレッドシート取り込み用）

## 次の実装候補
1. ワイヤー/PDF/PPTXからの制作物解析
2. カット候補のAI生成
3. AI画像生成 / 高品質参考画像検索
4. 出演者・場所・時間制約を使った自動再構成
5. ドラッグ&ドロップによる撮影枠の並べ替え
6. Excel/XLSXのレイアウト維持出力
7. クライアント確認用ビュー
8. バージョン管理・変更履歴
