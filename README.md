# 撮影設計AI KOBAN v50

## 今回の変更
- ①案件資料と「台割について」を分離。
- 台割PDF／デザインカンプを専用欄でアップロード可能。
- 台割構成をテキストで共有できる専用欄を追加。
- パンフレットは「PDF 1P＝パンフレット1P」、Webは「PDF 1P＝Web 1ページ」という前提をUIに明記。
- ②素材領域では、AIが台割を自動反映する方式をやめ、台割構成からページ骨格を作成。
- 各ページに素材を手動追加・編集できるように変更。
- AIは「素材候補を提案」する補助機能として残し、最終確定は人間が行う。
- 台割PDFはレイアウト確認用の参照資料として表示。
- 既存の案件資料AI解析は案件理解用として継続。

## 運用
1. ①で案件資料を追加。
2. 「台割について」に台割PDFと台割構成を入力。
3. 「AIに読み込ませる」で案件資料を解析。
4. 「素材領域を確認する」で②へ移動。
5. ページごとにPDFを見ながら必要な撮影素材を追加・修正。
6. 必要なら「AIに素材候補を提案してもらう」で補助候補を追加。
7. 確定した素材領域から③カット設計へ進む。

## 注意
AIによる台割の完全自動反映はv50では意図的に行いません。ページ構成を正とし、PDFはレイアウト・素材領域確認のために利用します。
